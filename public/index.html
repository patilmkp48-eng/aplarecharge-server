👥 नोंदणीकृत ग्राहक (Users Management)

कोणत्याही ग्राहकाच्या वॉलेटमध्ये पैसे जमा (+ Credit) किंवा वजा (- Debit) करा, किंवा फसवणूक करणाऱ्याला Block करा.

नाव मोबाईल नंबर वॉलेट बॅलन्स एकूण मिळालेला कॅशबॅक स्थिती वॉलेट व ब्लॉक नियंत्रण

💰 ऑपरेटर कमिशन आणि कॅशबॅक सेटिंग

ऑपरेटर सेवा API Operator Code API कंपनी कमिशन (%) ग्राहक कॅशबॅक (%) तुमचा निव्वळ नफा (%) चालू/बंद

⚡ ऑटोमॅटिक पेमेंट गेटवे सेटिंग (Method 2: Auto UPI Payment Gateway)

युजरने PhonePe/GPay वरून पेमेंट केल्यावर सर्व्हर स्वतः बँकेशी व्हेरिफाय करून ऑटोमॅटिक वॉलेटमध्ये पैसे जमा करेल (१००% फ्रॉड-प्रूफ).
